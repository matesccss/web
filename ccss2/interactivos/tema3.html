¿Qué método uso?

Árbol

Hay etapas (primero se elige una urna, una máquina, un grupo…) o los datos son porcentajes dentro de un grupo: «de los que…, el 30 %». Sirve para la probabilidad total y para Bayes.

Tabla

Se cruzan dos características y los datos son del total, incluida la intersección («el 20 % tiene las dos»). Si dan recuentos, se dividen entre el total.

Propiedades

Te dan directamente P(A), P(B), P(A∪B)… sin contexto. Se usan las fórmulas (o la pestaña «Sucesos»).

Del enunciado a la probabilidad

«A y B», «los dos»P(A ∩ B)
«A o B», «alguno», «al menos uno»P(A ∪ B)
«no A»P(A)
«ni A ni B», «ninguno»P(A ∩ B)
«solo A», «A pero no B»P(A ∩ B)
«solo uno de los dos»P(A ∩ B) + P(A ∩ B)
«no los dos a la vez»P(A ∪ B)
«sabiendo que B», «si B…», «de los B, el …%»P(… / B)
«al menos uno» en varias repeticiones1 − P(ninguno)

Propiedades

ContrarioP(A) = 1 − P(A)
UniónP(A∪B) = P(A) + P(B) − P(A∩B)
Solo AP(A∩B) = P(A) − P(A∩B)
Ninguno (De Morgan)P(A∩B) = 1 − P(A∪B)
No los dos (De Morgan)P(A∪B) = 1 − P(A∩B)
LaplaceP(A) = favorablesposibles
IncompatiblesP(A∩B) = 0
IndependientesP(A∩B) = P(A)·P(B)
Ojo: independientes no es lo mismo que incompatibles.

Condicionada

DefiniciónP(A/B) = P(A∩B)P(B)
IntersecciónP(A∩B) = P(B)·P(A/B)
ContrarioP(A/B) = 1 − P(A/B)
Condición BP(A/B) = P(A) − P(A∩B)1 − P(B)
Condición A∪BP(A/(A∪B)) = P(A)P(A∪B)

En el contrario de una condicionada, la condición no cambia.

Árbol

1.ª ramaP(suceso): P(A), P(B)…
2.ª ramacondicionadas: P(D/A)…
Final (camino)P(A∩D) = P(A)·P(D/A)
P. totalP(D) = P(A∩D) + P(B∩D) + …
BayesP(A/D) = P(A∩D)P(D)

Las ramas que salen de un punto suman 1. ¿Falta una? Pon x y 1 − x y usa la probabilidad total.

¿Qué distribución es?

Variable discretaTe dan una tabla xi, pi: μ = Σ pixi, σ² = Σ pixi² − μ²
BinomialRepito n veces lo mismo (independiente) y cuento éxitos
NormalMedida continua con media μ y desviación σ
AproximaciónBinomial con n grande: n ≥ 30, np ≥ 5, nq ≥ 5

Define siempre la variable: X = «número de …».

Binomial X ∼ Bi(n, p)

ProbabilidadP(X = k) = nk pk qn−k
Número combinatorionk = n!k!(n−k)!
Media y desviaciónμ = np   σ = √(npq)
Al menos unoP(X ≥ 1) = 1 − qn

Normal X ∼ N(μ, σ)

TipificarZ = X − μσ
Al revésx = μ + z·σ
P(Z ≥ k) = 1 − P(Z ≤ k)
P(Z ≤ −k) = 1 − P(Z ≤ k)
P(Z ≥ −k) = P(Z ≤ k)
P(k₁ ≤ Z ≤ k₂) = P(Z ≤ k₂) − P(Z ≤ k₁)
P(−k ≤ Z ≤ k) = 2P(Z ≤ k) − 1

Aproximación (Yates ± 0,5)

Bi(n, p) → N(np, √(npq))

P(X = a)P(a − 0,5 ≤ Y ≤ a + 0,5)
P(X ≤ a)P(Y ≤ a + 0,5)
P(X < a)P(Y ≤ a − 0,5)
P(X ≥ a)P(Y ≥ a − 0,5)
P(X > a)P(Y ≥ a + 0,5)
